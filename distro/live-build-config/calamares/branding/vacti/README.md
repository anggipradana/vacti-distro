# Calamares branding/vacti

`logo.png` (the square radar-shield icon) and `welcome.png` (the brand lockup banner) are committed,
rendered from the branding SVG sources (`welcome.svg` here; `logo.png` from
`distro/branding/logo/svg/vacti-icon.svg`). `branding.desc` sets the brand navy sidebar + accent
text, and `show.qml` is the brand slideshow. No Debian / Kali marks.

Re-render the PNGs with `distro/branding/render-assets.sh`.
