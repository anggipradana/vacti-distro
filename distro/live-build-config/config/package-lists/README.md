# package-lists

- `vacti-core.list.chroot` is GENERATED by `build-iso.sh` from the shared
  `../../packages/` manifest (`gen-live-build-list.sh`, honoring
  `VACTI_FULL_ARSENAL`). It is gitignored; do not hand-edit.
  - `build-iso.sh` then SUBTRACTS the packages in `../../packages/best-effort.list`
    from this hard list, because live-build installs a package-list all-or-nothing
    and a name apt cannot locate would abort the whole ISO build. Those best-effort
    packages are installed instead by `../hooks/normal/0330-vpn-besteffort.hook.chroot`
    with the same warn-and-continue semantics the golden/OVA path uses, so the ISO
    carries exactly what the OVA carries (OVA/ISO parity).
- `vacti-gui.list.chroot.in` is the GUI SKU add-on; `build-iso.sh` copies it to
  `vacti-gui.list.chroot` only when `VACTI_ISO_SKU=gui`.
